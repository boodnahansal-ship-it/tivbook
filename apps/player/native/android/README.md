# Android extras for the player app

- `res/raw/tivbook_place_available.wav`: TiVBook's own alarm sound for "place available" notifications.
- `google-services.json`: **put the file you download from Firebase here** to switch on phone alarms when the
  app is closed (see the setup guide). Without it, the app still rings whenever it is open.

The GitHub build copies these into the Android project automatically.
